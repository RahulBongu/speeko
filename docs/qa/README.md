# Speeko — Visual QA

Screenshots generated by the Playwright suites in `tests/e2e/routes.spec.ts` and
`tests/e2e/onboarding.spec.ts`. They are the visual record for every phase; a phase is
not done until these have been looked at, not just generated.

## Generate

```bash
pnpm build      # Playwright serves the production Next build + compiled API
pnpm e2e
```

The suite uses the installed Google Chrome (`channel: 'chrome'`), so no
browser download is needed. Outside CI it reuses an already-running web/API
server; stop stale servers if screenshots look like an older build.

## Limitations

- **Route screenshots are guest state.** P2 adds signed-in reward screens and
  API checks, but other authenticated pages (`/account` signed in) are still
  not captured.
- **Web only.** The Expo welcome screen and the release APK are not captured.
- **Interaction coverage is still narrow.** Deep lesson flow beyond completion,
  hearts exhaustion, pair reset, sign-out, and cloud sync on a second device
  need more tests. Onboarding, path switching, guidebook, checkpoint gating,
  practice due/trouble/unit flows, and the six-tap guest flow are covered.
- **Static viewport.** Screenshots do not catch overflow below the fold, dark
  mode (not implemented), or reduced-motion variants.
