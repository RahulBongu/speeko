# Speeko — Visual QA

Screenshots generated by the Playwright suite in `tests/e2e/routes.spec.ts`.
They are the visual record for every phase; a phase is not done until these
have been looked at, not just generated.

## Generate

```bash
pnpm build      # Playwright serves the production Next build + compiled API
pnpm e2e
```

The suite uses the installed Google Chrome (`channel: 'chrome'`), so no
browser download is needed. Outside CI it reuses an already-running web/API
server; stop stale servers if screenshots look like an older build.

errors occur, and no console errors are emitted. Fonts are awaited before the
shot so text does not render in a fallback face.

`contact-desktop.png` and `contact-mobile.png` are convenience composites of
the individual files. The per-route PNGs are the source of truth.

## Limitations

- **Guest state only.** No authenticated screenshots; sign-in/sign-up are
  captured as forms, not as a signed-in session. `account.png` shows the guest
  view. The "Your milestones" card is therefore not covered visually yet.
- **Web only.** The Expo welcome screen and the release APK are not captured.
- **No interaction coverage beyond the first exercise.** Deep lesson flow,
  hearts, pair reset, completion, sign-out, and cloud sync still need tests.
- **Static viewport.** Screenshots do not catch overflow below the fold, dark
  mode (not implemented), or reduced-motion variants.
